# 1. Which OSI layer handles error detection and flow control?
A. Physical
B. Data Link # correct answer
C. Network
D. Transport

The Data Link layer (Layer 2) handles frame synchronization, error detection (CRC checks), and flow control (e.g., Ethernet's pause frames). This is distinct from Layer 4's flow control (e.g., TCP windowing).
